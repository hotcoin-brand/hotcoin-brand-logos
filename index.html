📐 Naming Convention / 命名规范

All files follow the pattern: logo-{type}-{variant}-{color}-{bg}.{ext}

SegmentValues说明
typefull · mark · icon完整Logo / 方形图标 / 独立小图标
variantsquare · circle方形 / 圆形（仅mark类型）
colordark-green · light-green · white黑绿 / 白绿 / 白色
bgon-white · on-black · on-green白底 / 黑底 / 绿底（仅mark类型）
sizehd (高清) · default (标准)高分辨率版本标记
extpng · svg · jpg · ai文件格式

Example: logo-mark-square-on-white.svg = 方形图标 · 白底 · SVG矢量
例：logo-full-dark-green-hd.png = 完整Logo · 黑绿 · 高清PNG
